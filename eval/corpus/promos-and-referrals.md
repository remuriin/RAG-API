# Promos and Referrals

## Using a promo code
Enter a promo code on the fare estimate screen before you confirm a booking. Only one promo code can be used per trip. A promo code cannot be combined with a legally mandated discount (student, senior citizen, PWD or solo parent): if both could apply, the app automatically uses whichever saves you more. A promo code can be used together with the Tricycall Plus discount.

## Inviting friends
Share your invite code from Profile, then Invite friends. Your friend gets ₱30 off their first ride when they sign up with your code. This replaces BAGONGRIDE for them, since only one promo applies per trip. You get ₱30 in wallet credit after your friend completes their first ride. You can earn rewards for up to 10 friends per calendar month.

## Driver referrals
Drivers can invite other drivers from the driver app. The inviting driver earns a ₱500 bonus once the new driver is verified and completes 30 trips within their first 30 days. The bonus is added to the next weekly payout.

## When a promo does not work
A code may be rejected because it has expired, has been used the maximum number of times, does not apply to the ride type you chose, or is for new accounts only. The fare estimate screen shows the reason. Support cannot apply an expired code after the trip.
